# PDF Generator

A minimal, beginner-friendly PDF document generator built with
[Streamlit](https://streamlit.io) and [reportlab](https://www.reportlab.com/) —
add paragraphs, headings, and bullet lists as content blocks, then download
the whole thing as a real PDF file, built entirely in memory.

Built as a teaching project — see **`PDF_Generator_Mentoring_Guide.pdf`**
(itself generated by this app's sibling script, `build_guide.py`) for a
full walkthrough: building a PDF in memory with `io.BytesIO`,
`st.download_button`, and a real widget-identity bug found and fixed while
building this — a good worked example of a `st.form` gotcha.

## Run it

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

Then open the local URL Streamlit prints (usually `http://localhost:8501`).

## Files

- `app.py` — the app
- `requirements.txt` — dependencies
- `PDF_Generator_Mentoring_Guide.pdf` — the guide
- `build_guide.py` — regenerates the guide PDF from its source text (run `python3 build_guide.py` after editing it)
