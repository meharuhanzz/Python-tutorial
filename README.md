## Python in 15 Days

A full beginner Python course, one day per Git branch. Each day has its own
runnable code and a `README.md` explaining the concepts.

```bash
git clone https://github.com/meharuhanzz/Python-tutorial.git
cd Python-tutorial
git checkout day01
# read README.md, run the code, do the exercises
git checkout day02
# ...and so on
```

| Day | Branch | Topic |
|---|---|---|
| 1 | [`day01`](../../tree/day01) | Python basics: variables, data types, `print`/`input` |
| 2 | [`day02`](../../tree/day02) | Operators & type conversion |
| 3 | [`day03`](../../tree/day03) | Strings & string methods |
| 4 | [`day04`](../../tree/day04) | Conditionals: `if` / `elif` / `else` |
| 5 | [`day05`](../../tree/day05) | Loops: `for`, `while`, `break`/`continue` |
| 6 | [`day06`](../../tree/day06) | Lists |
| 7 | [`day07`](../../tree/day07) | Tuples & sets |
| 8 | [`day08`](../../tree/day08) | Dictionaries |
| 9 | [`day09`](../../tree/day09) | Functions |
| 10 | [`day10`](../../tree/day10) | Modules & the standard library |
| 11 | [`day11`](../../tree/day11) | File I/O |
| 12 | [`day12`](../../tree/day12) | Exception handling |
| 13 | [`day13`](../../tree/day13) | OOP I: classes & objects |
| 14 | [`day14`](../../tree/day14) | OOP II: inheritance & polymorphism |
| 15 | [`day15`](../../tree/day15) | Capstone: a command-line contact book |

Every `dayNN` branch has the same three files at its root:

- **`README.md`** — what you're learning today, explained, with examples
- **`main.py`** — runnable code demonstrating today's concepts
- **`exercises.py`** — practice problems (with TODOs) — try these yourself

Run any day's code with `python3 main.py` after checking out that branch.
